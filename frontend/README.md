# CloudStorage Frontend

High-performance, modern web application frontend for the Cloud File Storage System built with Vite, vanilla JavaScript, CSS3 design system, and official Supabase client authentication. Optimized for zero-configuration, zero-downtime deployment to **Vercel**.

---

## 🛠 Tech Stack

- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Core**: Vanilla HTML5 & Modern JavaScript (ES Modules)
- **Styling**: Vanilla CSS3 design system (Plus Jakarta Sans, responsive grid, dynamic dark-mode accents)
- **Authentication**: Official Supabase Auth (`@supabase/supabase-js`)
- **Hosting / CDN**: [Vercel](https://vercel.com/)

## ⚙️ Environment Variables

Copy `.env.example` to `.env` for local customization:

```bash
cp .env.example .env
```

| Variable | Required | Description | Example / Default |
| :--- | :--- | :--- | :--- |
| `VITE_API_BASE_URL` | **Yes** (Prod) | URL of the Spring Boot backend on Render | Local: `http://localhost:8080`<br>Prod: `https://your-backend.onrender.com` |
| `VITE_SUPABASE_URL` | **Yes** | Supabase Project URL | `https://xyzcompany.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | **Yes** | Supabase Anonymous Client Key (safe for public) | `eyJhbGciOi...` |

> ⚠️ **Security Warning**: NEVER place `service_role` keys or database credentials in frontend environment variables. Only the public `anon` key should be used.

## 🚀 Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

Open your browser at `http://localhost:5173`. When running locally on port 5173, the frontend automatically falls back to connecting to `http://localhost:8080` if `VITE_API_BASE_URL` is omitted.

### 3. Production Build
```bash
npm run build
```
Generates an optimized bundle in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 🔺 Deploying to Vercel

1. Log into your [Vercel Dashboard](https://vercel.com/) and click **"Add New..."** -> **"Project"**.
2. Import the Git repository containing this project.
3. Configure the Project Settings:
   - **Root Directory**: Click "Edit" and choose `frontend`
   - **Framework Preset**: `Vite` (automatically detected)
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Under **Environment Variables**, add:
   - `VITE_API_BASE_URL`: The HTTPS URL of your deployed Spring Boot backend on Render (e.g. `https://your-backend.onrender.com`).
   - `VITE_SUPABASE_URL`: Your Supabase Project URL.
   - `VITE_SUPABASE_ANON_KEY`: Your Supabase Public Anon Key.
5. Click **"Deploy"**.
6. Once deployed, copy your Vercel production domain (e.g., `https://cloudstorage-frontend.vercel.app`) and configure it in the backend's `CORS_ALLOWED_ORIGINS` environment variable on Render.
